Comandos GitHub

Git Init

O git init cria um novo repositório Git. Ele cria uma pasta oculta .git que armazena todo o histórico e configuração do projeto.

git init

Git Add

O git add adiciona arquivos ao "stage" (área de preparo), marcando-os para serem incluídos no próximo commit. Pode ser usado para adicionar arquivos específicos ou todos os arquivos de uma vez (com git add .).

git add .

Git Commit

O git commit salva as alterações preparadas no histórico do repositório, criando um "snapshot" do projeto em um determinado momento. Cada commit possui uma mensagem descritiva e um identificador único (hash).

git commit -m "Mensagem do commit"

Git Status

O git status exibe o estado atual do diretório de trabalho e da área de preparo, mostrando quais arquivos foram modificados, quais estão no stage e quais não estão sendo rastreados pelo Git.

git status
